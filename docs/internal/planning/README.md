# Japan WHV — Travel plan 2027–2028
## Summary

Draft twelve-chapter outline for the 2027–2028 Working Holiday stay, incorporating the proposal selected on October 22, 2026 and the Fujinomiya side trip during the second Tokyo stay. Longer city stays alternate with shorter regional chapters, including a Shikoku coastal road trip and a flexible October farewell. The first Tokyo chapter retains its existing planning; the new chapters contain only short summaries and empty planning sections, as requested. All dates remain tentative, and document review and approval are pending.
