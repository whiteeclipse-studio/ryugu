# Ryugu documentation agent instructions
## Scope

Ryugu is a documentation-only Japan Working Holiday planning vault. Follow the user's current instructions and the [documentation entrypoint](./README.md). Read the relevant [shared and category standards](../../hypatia/docs/standards/README.md) before dependent edits. The entrypoint records the current scaffold's unresolved applicability and governance points.

## Collaborative authoring

Work at the scope and pace explicitly requested by the user. A scaffold request authorizes structure and administrative boilerplate; missing substantive input stays TBD. Preserve existing decisions, draft status, sources, and revision history. Agents may prepare and check documents, but may not approve or accept them.

Keep synced files in the ChatGPT project's sources directory read-only. Distinguish verified facts, interpretation, assumptions, and unresolved questions when research is requested. Use current authoritative French and Japanese sources for legal, tax, immigration, and administrative claims.

For original Ryugu documents, use the MIT License and attribute copyright and revision authorship to Akane SHIMOKA, as explicitly requested by the user. Preserve the original copyright and authorship of imported third-party material.

All uncommitted changes to a document MUST share the same revision number; update its pending revision entry until those changes are committed.
