# 龍宮 
## Summary

The name **龍宮** (Ryūgū, “Dragon Palace”) refers to the undersea palace in the Japanese folktale of [Urashima Tarō](https://www.gov-online.go.jp/eng/publicity/book/hlj/html/201407/201407_09_en.html). It was chosen to evoke a journey into an unfamiliar world, reflecting the spirit of discovery behind this year in Japan.

**龍宮** is the documentation and planning vault for **Akane**'s Japan Working Holiday stay planned from October 19, 2027 to October 20, 2028.
